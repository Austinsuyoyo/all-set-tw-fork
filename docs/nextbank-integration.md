# 將來銀行存款串接：階段成果

## 範圍

- 官方 API 的 CAPTCHA 與單次帳密登入、唯讀查詢、登出；不自動重送帳密或接管登入。
- 主帳戶餘額、最近三個月交易、交易摘要與備註。
- 活存口袋及分頁交易；定存口袋解析與總額核對。
- 網站設定、互動式 CAPTCHA、Worker 同步與預設停用的排程。
- 同步採暫存後原子寫入；設定變更保護與口袋消失／重現處理。

## 驗證與限制

2026-09-27 已實測主帳戶、活存口袋、交易 API 及登出。使用者核對餘額與部分交易，並確認可看到支出。

後續發現交易識別碼跨月份重複可能造成覆蓋，已加入台灣交易日期區分，並以合成測試重現及驗證修正。修正後使用者已確認轉出支出可見；未逐筆驗證全部三個月明細。核對頁列出全部已查詢明細，不再限十筆。

2026-09-28 已完成個人正式部署與主帳戶／活存口袋同步驗收，使用者核對可見餘額與交易。定存口袋目前僅有合成測試；排程實際登入仍未完成真實驗收。

基金、美股、投資帳戶現金與持倉 API 尚未取得可驗證契約，未實作，亦未將商品推薦清單當作持倉。渣打實驗不包含在本提交。

## 本機核對

執行 `node scripts/test-nextbank-local.mjs`，開啟終端列出的 localhost 網址。可用環境變數 NEXTBANK_PROBE_PORT 指定埠。帳戶持有人自行輸入帳密與銀行驗證碼；完成唯讀查詢後登出。

銀行回應、帳密與 token 不寫入檔案；終端只輸出回應結構及筆數。畫面供使用者核對，不能作為已部署或資料庫同步成功的證據。

## 測試

從 repo root 執行 `npm run format:check`、`npm run typecheck`、`npm run test:backend` 與 `npm run test:unit`。連接器 self-check 包括加密、登入錯誤、交易識別、備註、口袋分頁與金額核對；Worker 測試包括設定競爭保護、排程及帳戶生命週期。
